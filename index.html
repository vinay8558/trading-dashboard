One-time setup — connect this dashboard to your private trading repo.

Create a GitHub token

Open github.com/settings/personal-access-tokens/new

Set Token name: bull-dashboard

Set Expiration: 1 year (or "No expiration" if you don't want to renew)

Set Repository access: "Only select repositories" → pick trading-agent

Grant read-only permissions

Scroll to Repository permissions → set:

Contents: Read-only

Metadata: Read-only (auto-selected)

Leave everything else as "No access". This token can only READ your repo, nothing more.

Generate & copy the token

Click Generate token at the bottom. Copy the token (starts with github_pat_…).

⚠️ You can only see it once — copy it now.

Paste it below

The token is stored ONLY in your phone's browser storage. It never touches any server.
